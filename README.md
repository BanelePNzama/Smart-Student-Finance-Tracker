📊 Smart Student Finance Tracker
- A web-based application designed to help students manage their finances by tracking income, expenses, and savings in a simple and user-friendly way.

🚀 Overview
- The Smart Student Finance Tracker helps students take control of their money by providing an easy way to:

- Record income and expenses
- Categorize spending
- Monitor monthly budgets
- Understand spending habits
- This project is built to solve a real-world problem many students face: managing limited finances effectively.

✨ Features
- Add Income & Expenses – Easily record bursaries, allowances, or any income, and track all spending.
- Categorize Expenses – Organize expenses by categories like Food, Transport, Books, etc.
- Auto Calculate Balance – Instantly see remaining budget after each transaction.
- Reports & Charts – Visualize spending patterns to understand where your money goes.
- Budget Warnings – Get alerts if you exceed your planned budget.

🛠️ Tech Stack

-HTML – structure
- CSS – custom styling
- Bootstrap – responsive UI and layout
- JavaScript – application logic
- Local Storage – data persistence
- Chart.js – financial data visualization
